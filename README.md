# Mini Hospital Emergency Management System

## CIT300 - Data Structures and Algorithms

This project is a Mini Hospital Emergency Management System developed
using Java.

## Data Structures Used

### 1. Binary Search Tree
Used to store patient records using Patient ID as the key.

Operations:
- Insert
- Search
- Delete
- In-order traversal

### 2. Queue
Used to manage emergency patients.

The Queue follows FIFO (First-In, First-Out).

Operations:
- Enqueue
- Dequeue
- Display waiting patients

### 3. Stack
Used to store completed treatment records.

The Stack follows LIFO (Last-In, First-Out).

Operations:
- Push
- Pop
- Display treatment records

### 4. Singly Linked List
Used to store each patient's previous hospital visits.

Operations:
- Add visit
- Remove visit
- Search visit
- Display visit history
